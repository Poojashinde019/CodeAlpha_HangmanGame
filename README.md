Hangman Game 🎮

Project Description

This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

Features

- Random word selection.
- Five predefined words.
- Six incorrect attempts allowed.
- User guesses one letter at a time.
- Displays win or game over message.

Technologies Used

- Python
- Random Module
- While Loop
- If-Else Statements
- Lists and Strings

How to Run

1. Download the project.
2. Open the folder in VS Code.
3. Run the following command:

python hangman.py
